# SCHWARZ

Учебный проект: вымышленный прокат немецких машин в Москве. Все машины в тёмных цветах.

| Папка | Что это | Vercel | GitHub Pages |
|---|---|---|---|
| `lite/` | сайт без 3D | https://schwarz-lite.vercel.app | https://maratch01-debug.github.io/schwarz-site/lite/ |
| `3d/` | 3D «Подиум» (Three.js) | https://schwarz-3d.vercel.app | https://maratch01-debug.github.io/schwarz-site/3d/ |

Оба проекта Vercel подключены к этому репо (Root Directory `lite` и `3d`): любой push в `main`
выкладывает новую версию сам. Сборка не нужна, в папках уже готовая статика.
